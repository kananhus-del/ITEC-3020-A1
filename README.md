## Project Description
K & J Steakhouse is a fictional restaurant website designed to showcase a selection of food items. The website includes three pages: Home, Menu, and About / Contact.

The Home page introduces the restaurant and highlights featured dishes. The Menu page displays available food items with their names, images, categories, prices, and ratings. The About / Contact page provides information about the restaurant and includes a contact form.

## JavaScript Interactions

The website uses JavaScript to implement the following interactive features:

1. Hamburger Navigation Menu: Allows users to open and close the navigation menu on smaller screen sizes.

2. Search Function: Allows users to search for specific dishes by name. The displayed items update automatically as the user types.

3. Cuisine Filter: Allows users to filter menu items by cuisine category, such as Italian, Japanese, Mexican, and American.

4. Sorting: Allows users to sort menu items by their highest or lowest ratings.

5. Favourite System: Users can add or remove dishes from their favourites. A counter displays the total number of favourited items.

6. Contact Form Validation: JavaScript checks that all form fields are completed and that the email address follows a valid format. Feedback messages are displayed to inform users whether their submission was successful or if corrections are needed.
